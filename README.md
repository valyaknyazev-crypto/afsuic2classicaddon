## 🇷🇺 Описание на русском

Вы достигли абсолютного предела стандартного **IC2 Classic**? Вам нужно хранить миллиарды EU и генерировать колоссальные объемы энергии? **AFSU** — это хардкорный эндгейм-аддон, который выведет вашу индустриальную империю на совершенно новый уровень.

### ✨ Главные нововведения
* **Блок AFSU (Advanced Flux Storage Unit):** Гигантское хранилище энергии, вмещающее миллиарды EU. Ультимативная батарейка для вашей базы.
* **Экстремальные солнечные панели:** Расширяет прогрессию четырьмя новыми тирами:
  * Квантовая панель (Quantum Solar Panel)
  * Фотонная панель (Photon Solar Panel)
  * Сингулярная панель (Singularity Solar Panel)
  * Абсолютная панель (Absolute Solar Panel) — генерирует безумное количество EU/т!
* **Высокотехнологичные механизмы:** *Advanced Assembler* (Продвинутый сборщик) и *Plasma Transformer* для создания и контроля экстремального напряжения.
* **Сверхпроводники:** Новые провода, способные выдерживать невероятные потоки энергии без риска плавления.
* **Продвинутое оружие:** *Advanced Saber* и *Quantum Saber* для защиты вашей фабрики.

### 🛠️ Инструкция по сборке
Для самостоятельной сборки мода из исходников (требуется Java 17) выполните:
```bash
./gradlew build
```
Скомпилированный `.jar` файл появится в папке `build/libs`.

## 🇬🇧 English Description

Have you reached the absolute limits of standard **IC2 Classic**? Do you need to store billions of EU and generate colossal amounts of energy? **AFSU** is a hardcore endgame addon inspired by legendary mods, designed to push your industrial empire to the next level.

### ✨ Features
* **AFSU (Advanced Flux Storage Unit):** A massive energy storage block holding billions of EU. The ultimate battery for your endgame base.
* **Extreme Solar Panels:** Extends solar progression with 4 new extreme tiers:
  * Quantum Solar Panel
  * Photon Solar Panel
  * Singularity Solar Panel
  * Absolute Solar Panel (Generates insane amounts of EU/t!)
* **High-Tech Machines:** Build the *Advanced Assembler* and *Plasma Transformer* to manage and craft extreme voltage components.
* **Super Conductors:** New cables capable of handling absolute endgame energy transfer rates.
* **Advanced Weaponry:** Craft the *Advanced Saber* and *Quantum Saber* to obliterate your enemies.

### 🛠️ Build Instructions
To build the mod from source, ensure you have Java 17 installed and run:
```bash
./gradlew build
```
The compiled `.jar` will be located in the `build/libs` folder.
